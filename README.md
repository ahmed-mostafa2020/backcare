# BackCare – رحلة تعافي ظهرك

تطبيق PWA شخصي لبرنامج منزلي متدرّج 8 أسابيع لأسفل الظهر: روتين صباحي ومسائي موجّه، سباحة مرتين أسبوعيًا، متابعة الألم، ولوحة تقدّم.

- يعمل بدون إنترنت بعد أول فتح (Service Worker).
- كل البيانات محفوظة محليًا على الجهاز (localStorage) مع تصدير/استرجاع نسخة احتياطية.
- لا يشخّص ولا يغني عن الطبيب أو أخصائي العلاج الطبيعي.
